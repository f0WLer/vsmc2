# Extended Tooling - Align Faces

###### This is a fork of [Vintage Story Model Creator 2 (VSMC2)](https://github.com/anegostudios/vsmc2). There is also an [`extended-tools`](https://github.com/f0WLer/vsmc2/tree/extended-tools) branch containing all of the additions together.

<img width="800" height="450" alt="alignfacespreview" src="https://github.com/user-attachments/assets/4fd53b2b-5493-4f0b-95b3-e781507a736a" />

Adds **Selection > Align Faces**, used to move an entire parent selection to align one of its nested elements' faces with face of another outside of its hierarchy.

After clicking **Align Faces** with a parent element selected in the tree, click on a face of *any element nested in the parent element*. Then click on a *parallel* face of any element *not* nested in the parent. The entire parent element assembly will reposition so that the two faces are aligned. 

*In the above preview, the parent element for the entire wall is selected before the tool is clicked. Then the face of an element from the wall is aligned with the face of an element on the body, which is separate from the wall's parent element.*
