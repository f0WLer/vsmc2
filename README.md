# Extended Tooling - Batch Name Children
###### This is a fork of [Vintage Story Model Creator 2 (VSMC2)](https://github.com/anegostudios/vsmc2). There is also an [`extended-tools`](https://github.com/f0WLer/vsmc2/tree/extended-tools) branch containing all of the additions together.

<img width="2046" height="720" alt="namechildrenpreview" src="https://github.com/user-attachments/assets/8ff143a7-c16d-4400-b67e-7df7dd3f5421" />


Adds **Selection > Name Children.**

Automatically renames and sequentially numbers the direct children of the currently selected element (i.e "<ParentName>N"), making larger element hierarchies easier to organize and manage.
